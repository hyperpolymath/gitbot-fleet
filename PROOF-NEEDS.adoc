  `proven-with-postulates`, `tested-only`, `argued`, `open`.

  Creusot (Pearlite contracts) and Verus by default, on the code itself (§1.2);

== Ledger: open obligations

These four obligations come from the pre-policy file. Each concerns the
behaviour of first-party code, so under PROOF-POLICY §1 the code mapping takes
precedence: Rust code is verified with Creusot (Pearlite contracts) and Verus
on the code itself (§1.2), and the cross-bot contract that stands apart from any one
implementation is an Idris2 interface. The earlier suggestion of Lean 4 for
"algebraic properties of confidence scoring" is not policy. If the confidence
scoring is stated as a theory theorem, true of any implementation, the source
is Agda, rechecked in Rocq and Lean; a statement about this repository's
functions is engineering and stays with Creusot.

None has a checker run against it, and none has a receipt. Each stays `open`
until a verifier discharges it.

(policy §1.2).
